# originalToDo（Windows版 ToDo アプリ）

Python（Tkinter）で作った Windows 用の ToDo アプリです。
PC 起動時に自動で立ち上がり、付箋のように画面端にタスクを表示します。

## 主な機能
- タスクの追加・削除
- SQLite によるデータ保存
- 常駐モード
- カラー設定
- UI フォルダでレイアウト管理

## ダウンロード
Releases から Setup.exe をダウンロードしてください。
